Project Paper

The project discusses the development of a deep learning and explainable AI system for plant disease detection. The proposed system addresses challenges of traditional manual methods by using CNNs for automated image analysis. Integrating Grad-CAM into XAI techniques enhances interpretability and transparency of model predictions, building user trust. The project covers data collection, model development, mobile app creation, and sensor system integration for real-time plant health monitoring.
